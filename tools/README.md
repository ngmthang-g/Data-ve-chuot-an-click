# Reproducible extraction tooling

The research bundle was generated by a custom static PE/CLR parser (`parse_dotnet.py`) that:

1. reads PE headers and CLR data directory;
2. maps RVA -> file offset;
3. parses `#~`, `#Strings`, `#Blob`, `#US` metadata streams;
4. enumerates TypeDef/MethodDef/Field/TypeRef/MemberRef/AssemblyRef/ManifestResource tables;
5. resolves managed tokens;
6. parses fat/tiny managed method bodies;
7. disassembles IL opcodes;
8. emits `metadata.json`, `methods.tsv`, `types.tsv`, call edges and targeted disassembly.

The complete parser source is preserved in the full research bundle `MouseHiddenClick-KB.zip` produced with this study. The GitHub KB stores the critical extracted facts and token-level evidence so normal consumers do not need to execute tooling or the analyzed EXE.

Static-only rule: the extractor reads bytes; it does not launch the target executable.
